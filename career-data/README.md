# career-data

Data root for the [career-ops](https://github.com/career-ops-hq/career-ops) skill
(`CAREER_OPS_ROOT`, set by `.claude/hooks/career-ops-setup.sh`).

Your CV (`cv.md`), `config/profile.yml`, `portals.yml`, `data/`, `reports/` and
`output/` are written here. Commit and push them to keep them between sessions.
